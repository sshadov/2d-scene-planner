# Disguise Scene Planner: локальный прототип

Это независимый локальный прототип будущего плагина Disguise Designer. Он работает без установки зависимостей: откройте `index.html` в браузере или поднимите любой локальный HTTP-сервер в этой папке.

В прототипе можно задать размеры помещения и добавить LED-экраны, поверхности, камеры, проекторы и световые приборы. Каждый объект получает стабильный `pluginId`, координаты `X/Y/Z`, поворот и вертикальную привязку. Сетка имеет фиксированный шаг 1 м. Планы сохраняются в локальном хранилище браузера, а «Экспорт JSON» сохраняет переносимый файл.

Главная кнопка «Экспортировать сцену» не обещает запись в Designer, пока адаптер не подключён. Она строит diff и показывает операции `создать`, `обновить`, `без изменений` и `оставить в Designer`, а при непустой сцене требует подтверждение.

Внутри Designer адаптер отправляет изменения через Python Execution API (`/api/session/python/execute`). Для отдельного локального HTTP-теста можно задать `window.DISGUISE_API_ORIGIN`, если Designer API находится не на том же origin, что страница плагина. Python Execution API предназначен для редких функциональных операций вроде создания объектов, а не для постоянного polling.

## Контракт адаптера Designer

Официальный Plugin API должен предоставить глобальный `window.disguiseSceneAdapter` с методами:

```js
{
  capabilities: { liveUpdate: true },
  inspectScene: async () => ({ objects: [{ id: "designer-id" }] }),
  createObject: async (payload) => ({ designerId: "designer-id" }),
  updateObject: async (designerId, changedFields) => undefined
}
```

`createObject` и `updateObject` получают только данные, принадлежащие плагину. Удаления в контракте нет намеренно: объекты, исчезнувшие из плана, остаются в Designer.
